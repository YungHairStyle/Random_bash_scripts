# Shell utilities

A small collection of personal file-conversion and transfer scripts.

- `convert_mod_files.sh`: converts MOD video files using FFmpeg.
- `convert_vob_files.sh`: converts VOB video files using FFmpeg.
- `send_files.sh`: file transfer helper; review its destination and paths before use.
- `pishrink.sh`: a copy of [PiShrink by Drewsif](https://github.com/Drewsif/PiShrink), retained with its upstream attribution. PiShrink is third-party software, not my original implementation.

Review each script before execution and supply your own paths. The conversion scripts require FFmpeg and may expect an output directory to exist. PiShrink operates on disk images and has separate system requirements documented upstream.

These are standalone personal utilities rather than a maintained command-line package.
